VibeSlash 指令助手

Claude Code、Codex 命令速查表：不用背命令，按一下就出来。

在 claude.ai/code 的输入框开头输入 / 会弹出联想；按 Alt+K 或点右下角的 / 按钮打开完整指令面板。

基本设置

如果 Claude Code 网页版自带的指令菜单与之冲突，可以关掉这一项，只用快捷键和悬浮按钮。

插入没反应时再填写：在网页版输入框上右键「检查」，复制能唯一选中它的 CSS 选择器。

自定义指令

把仓库里的技能（Claude Code 的 .claude/skills、.claude/commands，Codex 的自定义提示词 /prompts:名称，DeepSeek Harness 的 .dsh/skills）或 MCP 提示词加进来，联想、面板和弹出页里会一起显示；与内置指令同名时覆盖内置说明。

    内置指令

    取消勾选的指令不会出现在联想、面板和弹出页里。
